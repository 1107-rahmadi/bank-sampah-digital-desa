 RINGKASAN STRUKTUR
================================================================================

  app/
    controllers/   -> 7 controller  (Admin, Auth, Home, Kades, Nasabah,
                                Password, Pengelola)
    helpers/      -> 5 helper     (AkunGuard, auth, money, render, util)
    models/       -> 14 model     (Analytics, AuditLog, BankSampah, Desa,
                                HargaSampah, KategoriSampah, MutasiSaldo,
                                Nasabah, Notifikasi, PengajuanPencairan,
                                Pengepul, StokSampah, TransaksiBeli,
                                TransaksiJual, User)
    views/        -> 5 area view  (admin, auth, kades, nasabah, pengelola)
                      + layouts/ dan partials/ global

  api/            -> 9 endpoint + folder sync/ (2 file)
  config/         -> 3 file konfigurasi
  database/       -> migrations/ (6), patches/ (1), seeds/ (1) + skrip setup
  lib/            -> 4 file homemade + tcpdf/ (pustaka pihak ketiga)
  public/         -> front controller + assets (css, js)
  tests/          -> 3 file uji
  tools/          -> 1 skrip smoke test
  bank_sampah/    -> versi lama/legacy (arsip)

  Catatan:
  - Folder bank_sampah/ adalah implementasi lama sebelum refactor ke app/.
  - Folder lib/tcpdf/ adalah pustaka pihak ketiga (bukan kode proyek).
  - Folder .git/ tidak ditampilkan pada diagram ini.

================================================================================
 ALUR REQUEST (ringkas)
================================================================================

  Browser / Mobile
        |
        v
  public/index.php  (front controller)
        |
        v
  app/controllers/*  ->  app/models/*  ->  MySQL (config/database.php)
        |                    |
        |                    +-> audit_log (AuditLog)
        v
  app/views/*  (dengan app/helpers/*)
        |
        v
  Response ke pengguna

  Untuk API (mobile):
  Browser/Mobile -> api/index.php -> api/*.php -> sync/{pull,setoran}.php -> DB
